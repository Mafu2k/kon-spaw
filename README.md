# KON-SPAW

Strona firmowa **KON-SPAW** — konstrukcje stalowe oraz cięcie laserem, CNC i waterjet.
Zbudowana w React + Vite z Tailwind CSS i animacjami (GSAP, Three.js).

## Stack

- React + Vite
- Tailwind CSS
- GSAP, Three.js

## Uruchomienie

```bash
npm install
npm run dev
```

Build produkcyjny: `npm run build`, podgląd: `npm run preview`.
